# Nexa Website v4.1.0

**Date:** 2026-10-03

## Scope

This checkpoint refines the bilingual static website for the Mobile course
milestone. Public pages describe Nexa product scope, team context, domain
flows, legal information, and current implementation limits.

The copy and navigation are aligned across visitor-facing content. Product
descriptions continue to distinguish target scope, technical implementation,
acceptance, and production readiness.

## Verification boundary

This release note records a source review of static HTML, CSS, JavaScript,
relative links, and referenced assets. It does not claim public hosting, an
operational application endpoint, application credentials, product acceptance,
system acceptance, or production readiness.

## Open items

Public deployment, live application access, and any future service commitments
remain outside this static website checkpoint.
